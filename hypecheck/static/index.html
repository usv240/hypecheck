Stop health hype at its source.

Most health hype is written before a journalist ever sees it. A third of university press releases claim more than their study found, and most news repeats them. HypeCheck checks every sentence against the paper before the release goes out, has Claude rewrite what overclaims, and checks the rewrite again.

One overclaim travels from a press office to millions of readers.

The research is clear about where health hype starts, and that fixing it at the release works. HypeCheck sits at the one point where a single correction changes everything downstream.

At the end of this chain is someone at a kitchen table who reads that their pills might do more harm than good and quietly stops taking them. Fix the sentence before it leaves the press office, and that reader never sees it.

Fixing the release fixes the news, and costs nothing.

A randomised trial in nine real press offices aligned releases with the evidence: news headlines matched the evidence far more often, and coverage did not drop (Adams et al., BMC Medicine 2019). The free human service that reviewed releases closed in 2018; nothing has automated it until now.

A small model judges. A large model writes.

Claude can be talked out of a “no”; a decision model can't. It only returns a probability, and plain code decides what happens next.

  1. Claude on Amazon Bedrock

    Tries to publish

    The agent calls its publish_release tool with the draft.

  2. Strands Decider 2B

    Rates every claim

    no link → linked → may cause → causes, for the paper and each sentence.

  3. Claude on Amazon Bedrock

    Rewrites what's blocked

    Only the flagged sentences go back, with the reason.

  4. Strands Decider 2B

    Re-checks, then publishes

    The rewrite faces the same gate. After 3 tries a person decides.

Limits we measured

  • At the strict threshold it catches 39% of exaggerations (95% CI 30–47%): a safety net, not an editor.
  • The animal-to-human hint is weak (AUROC 0.61 on 45 releases), so it never blocks.
  • 563 test pairs give wide intervals: accuracy is a tie with the published best (0.4735) and with Opus. The false-alarm gap to every Claude model is far outside chance.
  • This demo server runs Decider on a CPU, about six times slower than a GPU.

Drop the same gate into any agent.

Anything that must not say more than its source: summaries, RAG answers, patient leaflets, release notes. Use the open-source gate below, call the free REST API, connect over MCP, calibrate on your own data, or deploy into your own AWS account. Get a free API key →

# pip install strands-agents · strands-decider serve … --port 8099 from decision_pattern import Decider, ClaimFidelityGate, load_threshold gate = ClaimFidelityGate( Decider(), source=lambda: paper_conclusion, # what the text must not exceed tool_name="publish_release", text_arg="text", threshold=load_threshold("calibration.json", "0.1"), # BLOCK → Guide (rewrite) review_threshold=load_threshold("calibration.json", "0.2"), # REVIEW → listed, not blocked ) agent = Agent(model="us.anthropic.claude-sonnet-4-6", tools=[publish_release], interventions=[gate])

Questions, answered plainly.

What is Strands Decider 2B?

A small, open decision model from AWS Strands Labs (Apache-2.0). It doesn't write text: give it text and a typed question (yes/no, pick one, or a score) and it returns an answer with a calibrated probability in a fraction of a second, on hardware you already own.

What does Amazon Bedrock do here?

Bedrock serves Claude, which drives the agent and rewrites flagged sentences. The agent itself runs on Amazon Bedrock AgentCore Runtime.

Why not just ask Claude whether the release exaggerates?

We measured it: on the same 563 pairs, Claude flagged 29.6–44.9% of faithful releases depending on the model, Opus included. Decider with a calibrated threshold flagged 6.7%. Claude also can't be trusted to check its own rewrite, so Decider does.

What is “conformal calibration”?

A standard statistical recipe for turning model scores into a cut-off with a guarantee: set it on known-faithful examples so at most 10% would be flagged. If new text resembles the calibration set, the same rate holds; we measured 7.7%.

What do BLOCK, REVIEW and OK mean?

BLOCK: above the strict threshold; Claude must rewrite. REVIEW: between the two thresholds; not blocked, but listed for an editor. OK: below both.

Where does it run on AWS?

The page and Strands Decider run on Amazon EC2 behind Amazon CloudFront. The agent runs on Amazon Bedrock AgentCore Runtime (or in-process on EC2 if you choose), calls Claude through Amazon Bedrock, and reaches Decider through a key-protected endpoint whose key lives in AWS Systems Manager Parameter Store.

Is my text stored?

Only a published release is written to the server's outbox; drafts are not kept.
